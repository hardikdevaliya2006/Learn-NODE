# **What is node.js?**

## **Introducation**

- Node.js is a runtime environment that allows you to run JavaScript outside the browser (like on a server or your computer).
- Normally, JavaScript runs only inside a web browser (like Chrome, Firefox).
- Node.js makes it possible to run JavaScript directly on your machine, just like `Python` or `Java`.

> Key Points in Easy Language:

- Built on Chrome’s V8 engine → Makes JavaScript super fast.
- Used for backend → You can create `servers`, `APIs`, and handle `databases`.
- Comes with `npm` (Node Package Manager) → Lets you use ready-made packages and libraries.
- Non-blocking & `asynchronous` → Handles multiple tasks at once, so it’s great for real-time apps like chat apps, streaming, etc.

> In short:
> **Node.js** = JavaScript + Outside Browser + Server-Side Power

## **History of Node.js**

**1. Before Node.js (1990s – early 2000s):**

- JavaScript could only run inside browsers (like Chrome, Firefox, IE). If you wanted backend/server-side code, people used languages like PHP, Java, or Python. JavaScript was only for making websites interactive (frontend).

**2. 2008 – V8 Engine (Google Chrome):**

- Google created the V8 JavaScript engine for Chrome. V8 made JavaScript much faster because it converts JS code into machine code directly. This speed boost inspired developers to try running JS outside browsers.

**3. 2009 – Node.js Born:**

- **Ryan Dahl** created Node.js in 2009.
- **His idea:** use the V8 engine + event-driven, non-blocking I/O so servers can handle many requests at once.

- This solved the problem of slow, blocking server programs (like Apache with PHP).

**4. 2010 – npm (Node Package Manager):**

- npm was introduced. It allowed developers to share and install packages/libraries easily. This made Node.js grow very fast, as developers didn’t have to reinvent the wheel.

**5. 2011–2015 – Growing Popularity:**

- Big companies (LinkedIn, PayPal, Netflix, Walmart) started using Node.js. It became popular for building real-time apps (chat, streaming, APIs).

**6. 2015 – io.js Split and Merge:**

- Some developers created a separate project called io.js (to add features faster). Later, io.js and Node.js merged back. This improved the governance of Node.js (open-source community-driven).

**7. Now :**

- Node.js is one of the most popular backend technologies. It powers web apps, APIs, microservices, real-time apps, IoT, and more. The ecosystem is huge thanks to npm (world’s largest package registry).
