# **Frameworks**

## **Opinionated Framework**

- The framework has a fixed way of doing things. Gives you rules, structure, and best practices. You must follow its style. Easier for beginners (less decisions). Less flexible if you want to do things differently.

**Example:**

- Angular (for frontend) → It tells you how to structure files, how to write code.
- Rails (Ruby on Rails) → Very opinionated backend framework.

## **Unopinionated Framework**

- The framework gives you freedom to do things your own way. No strict rules → You decide the structure, tools, and patterns. More flexible, you can build however you like. Can be confusing for beginners (too many choices).

**Example:**

- Express.js (for backend) → You decide folder structure, middleware, etc.
- React.js (for frontend) → Only UI library, no strict rules for project structure.
